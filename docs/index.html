About. The Real GDP Tracker is an independent replication of the Atlanta Fed's GDPNow model and is not affiliated with the Federal Reserve Bank of Atlanta; GDPNow is the Atlanta Fed's model, and the published GDPNow figures shown here are read from the workbook it posts. The replication re-estimates the model's parameters each day from public data (BEA, Census, BLS, Federal Reserve Board and others); it does not use the Atlanta Fed's data or parameters except in the test that checks the code.

The quarter after the one being estimated appears while the latest quarter has ended but BEA has not published its advance estimate; no GDPNow figure exists for it.

How this was tested. Before it ran daily, the code was tested on the Atlanta Fed’s own data (the 3 October 2026 workbook). Given GDPNow’s inputs and parameters, it reproduces the published nowcast to 1.5×10−7 percentage point, with all 13 components and contributions matching. The test then re-estimates every parameter and rebuilds the data from public sources, and shows where each gap comes from. Details of the testing, and of the method, code and data behind the tracker, are available on request.

Contribution is each indicator's effect on the nowcast relative to an average quarter (percentage points). "Behind" is how many months the latest published value trails the current month; the model pairs each indicator with historical quarters that had the same lag.

How it works

The model is a real-time ridge MIDAS regression (mixed-data sampling): quarterly GDP growth is regressed directly on the last six months of each monthly indicator, with weekly and daily series averaged to months. Each indicator's six lags are compressed into three numbers (level, slope, curvature) by a Legendre polynomial, which is a flexible way of letting recent months count more or less. A ridge penalty, chosen by leave-one-out cross-validation, keeps the many coefficients in check.

  • Real time. Every day the model is refit on the data vintage published that day (St. Louis Fed's ALFRED), so the ragged edge is what was actually available. Each past quarter is compared at the same point in its quarter, with the same publication lags as today.
  • Per person. The model forecasts GDP growth minus population growth and adds a population assumption (the last four quarters' growth) back. This stops the average growth rate it learns from carrying a demographic trend that has since faded.
  • Target. BEA's advance estimate of real GDP growth. Training uses 1992Q3 onward and leaves out 2020 and 2021.
  • Two versions. The 14-indicator model uses the series below; the 3-indicator model uses only industrial production, the Chicago Fed financial conditions index and the 10-year minus 3-month spread, the information set of Chan's MIDAS tutorial.

Indicators

The goods and services trade balance was tested and dropped: before COVID it carried the largest weight, but its extreme swings in 2022 and 2025 produced the worst misses.

How the specification was chosen

Each step was chosen after seeing the previous step's errors, so the results here are not a clean out-of-sample test of the final specification. Full write-up, code and every variant: MIDAS.md.

Data timing and limits

  • Indicator history is read from the vintage published that day (revised); only the newest observations are first releases. Weekly jobless claims before 2009 and the Chicago Fed index before 2011 have no archived vintages, so current data cut at the forecast date are used.
  • The October 2025 unemployment rate and CPI were never published (government shutdown) and are interpolated.
  • Not used: surveys such as ISM, real consumption detail, construction, trade detail. They are part of what GDPNow has and this model lacks.
  • The daily tracker runs the same algorithm as the evaluation, but accuracy was measured only at the four dates per quarter above.
